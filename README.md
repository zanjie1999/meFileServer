# 咩FileServer
一个单文件简易文件服务器，点开即用，支持文件目录断点续传上传下载  
写这个程序的原因是因为想从朋友那传单文件50G文件过来，怕因为网络原因传一半断了只能重传，又不想装同步软件

方便的让别人给你不限速的直连传文件，无论是你传给他还是他传给你，无论有多少文件，文件有多大都不是问题  
对方无需安装任何软件！你无需进行任何配置，只要运行一下（这或许是史上最简单从iPhone导出照片的方式）  
假如你有公网IP，那你可以直接把端口映射出去，给你的朋友传文件，或是找他要文件，对方只需要打开浏览器

## 使用方法
在右侧Releases下载exe文件，放到需要共享的目录直接运行即可  
其他操作系统下载 `meFileServer.py` 源文件，使用终端运行 `python3 meFileServer.py` 启动  
比如先打开终端，`cd`空格把想共享的文件夹拖进来，回车后输入`python3`空格把`meFileServer.py`拖进来，回车即可启动服务器

## 补充说明
使用 `localhost`、`127.0.0.1` 或 `HTTPS` 访问时，浏览器会优先使用原生目录访问 API，支持完整的文件夹上传和下载。  
使用 `HTTP` 访问时，或者使用不兼容的浏览器时，文件夹上传会自动回退为兼容模式，此时不会上传保留纯空文件夹。文件夹下载会改为逐个下载文件，浏览器可能要求允许此站点连续下载多个文件。
